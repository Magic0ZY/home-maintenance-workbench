# 巡检规则全文（存进数据表用）

这份是**完整规则**，约 5 千字。它不粘在云端任务里，而是**存进「AI任务注册表」的 `指令全文` 字段** —— 任务里只粘[短提示词](巡检任务提示词.md)。

## 为什么要这样分

云端任务的提示词输入框**有长度上限（实测约 1,455 字符）**，超出会**静默截断**（不报错，就是默默少了一段）。完整规则 5 千字，直接粘进去必然被截。

所以采用**规则外置**：

| 放哪 | 内容 | 长度 |
|---|---|---|
| 数据表 `指令全文` 字段 | 完整规则（下面那段） | 约 5 千字 |
| 云端任务的提示词 | 短提示词，只负责"去表里读规则并执行" | 约 900 字 |

好处：**改规则只需改表里的字段，不用重新贴任务。**

## 用之前要替换的占位符

规则里的表 ID 都写成了 `<xxx表ID>` 这种占位符。**替换成你自己空间里的真实表 ID** 才能用（表 ID 在你的数据表链接里，或让 WorkBuddy 建表后告诉你）。

【说明书链接的硬规矩（2026-09-17 补充，务必遵守）】
- **只在两种情况下写**：① 主人原话里给了链接（照抄）；② 你能确认是**该型号的用户手册／使用说明书**页面。
- **严禁**拿“帮助中心 / 售后政策 / 退换货说明 / 配件商城 / 品牌首页 / 商城首页”这类**通用页面**充当说明书；同一个链接**不要重复挂到多条耗材上**（挂一次在设备档案上就够）。
- 搜索到的链接，**必须先核对页面确实是该型号的说明书**（标题或正文出现“说明书／用户手册／使用指南”且型号对得上）才写；**核对不了就留空**，并在结果里写明「说明书链接待补」。
- 说明书优先填在**设备档案**（一处即可）；只有某条耗材有**专属**说明书时，才写在那条维护项上。
① 新增耗材/维护项 → 写「家庭维护清单」。**建之前先查「设备档案」里有没有这台设备：没有就先按 ⓪ 建档**；维护项的「所属设备」必须与设备档案的「设备名」**一字不差**（多了少了空格、简称/全称不一致，页面就会归成两组）。同「所属设备」+同「维护项」已存在就不重复建，改为补缺口字段；周期、动作按这类耗材的常识给（清洗类 7~30 天、滤网/耗材更换类 90~180 天），并在结果里说明"周期是按常识预填，可按实际调整"。
② 记一笔消费 → 写「家庭账本」（<家庭账本表ID>）：日期、事项、类别（饮食/日用/居家/维护/出行/人情/其他）、金额、记录人、备注；
③ 日用品用完/补货 → 更新「日用品库存」；
④ 某件维护做完了 → 写「维护日志」（<维护日志表ID>）并把对应维护项「上次维护日期」更新为今天；
⑤ 新增固定费用/账单 → 写「固定费用台账」；
⑥ 新增节日/生日/纪念日 → 写「节日与生日」；
⑦ 新增宠物 → 写「宠物档案」（<宠物档案表ID>：名字/类型（猫、狗、其他）/品种/生日/体重kg/绝育/备注）；说"某只洗澡了/驱虫了/打疫苗了" → 找到「宠物护理」对应记录把「上次日期」更新为今天，没有就先建一条（「宠物」「项目」「上次日期」必填；「周期天数」原话没给就留空并提示待补）；
⑧ 登记物品（护肤品、药品等）→ 写「物品归档」（名称/品类/位置/入库日期/保质期至/开封日期/数量/状态/备注）；主人问"某样东西放哪了" → 在「物品归档」按名称检索，回答「位置」，空则答「未登记位置」；问"什么快过期" → 报保质期临近的记录；
⑨ 宠物相关设备（饮水机、猫厕所、喂食器）→ 在「设备档案」上把「归属模块」设为多选（可同时勾「家电」和「宠物」）、「关联宠物」填名字（多只共用填「共用」）；**不需要**在每条耗材上重复标归属。猫粮、猫砂这类 → 写「日用品库存」并填「宠物」（支持「共用」）与「单位」（袋/箱/卷/瓶…）；
⑩ 成员相关 → 写「家庭成员」（<家庭成员表ID>）；改名时同步更新各表引用字段（维护项/护理/准备的「负责人」、节日生日的「关联成员」、账本的「记录人」），维护日志的「操作人」保持不变；**「权限」只有主人能改成管理员**，AI 不主动改权限；
⑪ 电器设备相关（"加一台设备""这台设备搬到主卧了""说明书链接是…"）→ 写/改「设备档案」（<设备档案表ID>）；**设备改名要同步更新「家庭维护清单」中「所属设备」等于旧名的记录**；删设备不动维护项；说明书链接写在设备档案上（耗材专属的说明书才写在维护项上）。**这是所有"设备"类请求的落点**——买新电器、搬设备、补说明书，都先落到这里。
⑫ 物品搬家 → ① 只是箱子/盒子整体换地方 → 改「存放位置」那条记录的「上级位置」（物品记录不用动）；② 一批物品直接换位置 → 逐条更新「物品归档」的「位置」。
【硬性约束】只做原话明确要求的那件事，不得顺手做别的；原话没说的字段一律留空，**禁止猜测或补全**（金额、型号、日期、周期尤其不许编）；找不到表或信息不足时不要瞎写，在结果里写「需要补充：…」。
【结果格式】三段：① 做了什么（一句话）；② 落表明细（哪张表、哪条记录、record_id）；③ 留空待补字段（没有就写「无」）。

【第 3 步 · 防臆断】
结果只写数据里能直接核对的事实（名称、日期、库存、单价、推算结论）。不得凭印象声称「记录重复」——只有查到两条及以上 record_id 不同且名称完全相同的记录才可提示，并列出各自 record_id 与囤货数量；查不到就不提。不确定的写「待确认」，不下结论。
