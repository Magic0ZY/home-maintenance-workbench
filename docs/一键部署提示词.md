# 一键部署提示词（复制给 WorkBuddy 用）

**你不需要手动建表、改代码、传页面。** 把下面的提示词复制给 WorkBuddy，它会把整套工作台配好。

---

## 怎么用

1. 打开 WorkBuddy（手机或电脑都行）
2. 新建一个会话
3. 把下面第一段**原样复制**过去发送
4. 按它的提示逐步完成（分几轮，每轮都会告诉你进展）

> 大概率要分 3 轮走完：**建表 → 部署页面 → 配定时任务**。不用一次贴完，跟着它的节奏来就行。

---

## 第 1 轮：建数据表

```text
帮我部署一套「家庭维护工作台」。这是一套跑在云端资料库上的家务管理工具。

【本轮任务】只做建表这一步，不要做别的。

【源材料】
从 GitHub 读这个仓库：
https://github.com/Magic0ZY/home-maintenance-workbench

重点读 docs/数据模型.md —— 里面有 17 张表的完整字段定义
（表名、字段名、字段类型、选项值），以及「字段值格式对照表」。

【要做的】
按 docs/数据模型.md 的定义，在我的空间里建这 17 张表。

要求：
1. 字段名、字段类型必须与文档完全一致，特别是：
   - 日期类字段用「日期」类型
   - 单价/金额用「货币」类型
   - 房间/类别/状态这类用「单选」，选项值照抄文档
   - 「说明书链接」用 URL 类型，「说明书图片」用图片类型
2. 建完后给我一份清单：表名 → 表 ID
3. 暂时不要建页面、不要配定时任务

【如果读不到 GitHub】
告诉我，我会把 docs/数据模型.md 的内容直接贴给你。
```

**这一轮结束你应该拿到**：17 个「表名 → 表 ID」的对照。

---

## 第 2 轮：部署工作台页面

```text
继续部署「家庭维护工作台」，本轮做页面。

【本轮任务】把工作台页面部署到我的空间。

【源材料】
GitHub 仓库：https://github.com/Magic0ZY/home-maintenance-workbench
要用的文件：page/index.html（单文件主程序，约 143 KB）

【要做的】
1. 读取 page/index.html
2. 找到里面的配置块 var DB = { ... }，
   把 17 个占位符（YOUR_MAINT_DB_ID、YOUR_LOG_DB_ID …）
   替换成上一轮建好的真实表 ID
3. 把这个页面部署成我能用手机打开的链接
4. 把链接给我

【验收要求】
- 打开链接后左下角同步状态应显示「已同步」（不是「离线预览」）
- 「今天」「维护」「台账」几个页签里能看到内容
- 如果显示「N 张表未加载」，说明表 ID 没配全，请检查后重试

【注意】
不要修改页面的其他任何部分，只替换 var DB 里的那 17 个值。
```

**这一轮结束你应该拿到**：工作台的访问链接。

## 第 3 轮：配定时巡检

```text
继续部署「家庭维护工作台」，本轮配自动巡检。

【本轮任务】配置云端定时任务，让 AI 定期帮你盯着该做的事。

【源材料】
GitHub 仓库：https://github.com/Magic0ZY/home-maintenance-workbench
要读的文件：docs/AI任务配置.md

【要做的】
1. 按 docs/AI任务配置.md 的说明，把完整的巡检规则
   写进「AI任务注册表」表的「指令全文」字段
   （规则较长，注意不要截断）
2. 新建一个云端定时任务：
   - 名称：家庭维护台·信箱巡检
   - 频率：每 6 小时一次
   - 提示词：按文档里那段的「元提示词」（约 1200 字，不是完整规则）
3. 手动跑一次验证，确认能正常读写
4. 告诉我：任务频率、下次运行时间、这次运行结果

【说明】
这个任务带「门控」——没事发生时它跑 2 步就退出，几乎不花额度。
所以 6 小时一次是安全的。
```

**这一轮结束你应该拿到**：一个会自动帮你盯着家务的 AI 巡检任务。

## 常见问题

### 读到 GitHub 失败怎么办？

国内网络访问 GitHub 需要代理。如果 WorkBuddy 报网络错误：

1. 先确认你的代理开着
2. 或者让我给你开代理的办法

如果实在读不到，回一句：「读不到 GitHub，请让我手动提供文件」，然后我会把需要的文件内容贴给它。

### 只想要部分功能？

不需要 17 张表全建。最小可跑是 **7 张核心表**：

维护清单、维护日志、固定费用台账、节日与生日、日用品库存、任务请求表、AI任务注册表。

告诉 WorkBuddy「只建这 7 张」，其余留空 —— 页面有容错，对应模块显示为空，不影响使用。

### 不想用 AI 巡检？

那就跳过第 3 轮。**前两轮做完就已经能用**：到期提醒、库存、费用、节日生日这些都靠页面自己算，不依赖 AI。

### 部署完怎么日常使用？

见 [`使用说明与快速上手.md`](使用说明与快速上手.md) 的「日常使用」一节。

## 附：这套东西的边界

为了让 WorkBuddy 部署得顺，有几点它需要知道（你也可以自己了解）：

| 事项 | 说明 |
|---|---|
| 权限 | 页面上那个"管理员密码"不是安全机制，只是防误操作。真正的权限边界是**数据表的分享设置** —— 给家人开"查看"就改不了 |
| 时区 | 写入日期时间一律写**北京时间**。平台按写入时的字面值回读，不做时区换算 |
| 备份 | 页面的「我的」页有一键快照。**新增表之后要同步更新代码里的备份名单**，否则新表没备份 |
| 成本 | 定时任务的额度消耗主要在"有事"的时候；无事时门控会让它 2 步退出 |
